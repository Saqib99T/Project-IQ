Self-Hosted Firecrawl Setup (100% Free)

  1. Run: docker-compose -f docker-compose-firecrawl.yml up -d
  2. API will be available at http://localhost:3002
  3. Use any value for API key (e.g. fc-selfhosted) — no account needed
  4. Click Test Connection to verify, then Save

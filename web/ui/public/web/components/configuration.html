Session Settings

Control how long a user can be idle before their session is automatically ended.

min

A warning is shown 2 minutes before the session ends. Set to 0 to disable auto-timeout.

How it works:
After X minutes of inactivity the user sees a warning.
If they don't respond within 2 minutes, the session ends automatically.

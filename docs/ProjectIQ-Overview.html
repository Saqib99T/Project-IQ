Capabilities
Core Feature Set

A comprehensive set of capabilities spanning conversational AI, ITSM automation, knowledge management, and live agent collaboration.

🤖

Conversational AI Engine

Multi-turn dialogue management powered by the ML Platform with transformer-based intent classification, named entity recognition, and policy-driven conversation flow. Handles 36+ intents with confidence scoring, frustration detection, and graceful fallback escalation.

DIETClassifier TEDPolicy RulePolicy Slot Filling
🎫

ITSM Ticket Automation

Full lifecycle ticket management through natural language. Users create, update, query, and resolve tickets via conversation — no portal navigation required. Supports urgency classification (Low/Medium/High), issue categorisation (Hardware/Software/Network), and follow-up threading.

Create Update Status Check Resolve
🧠

Semantic Knowledge Base

Hybrid search combining keyword matching with dense vector similarity using Sentence Transformers (all-MiniLM-L6-v2, 384-dim). Automatically ingests ITSM knowledge base articles, supports section-level retrieval, and provides confidence-scored answers with source attribution.

Semantic Search Vector Embeddings FAQ Matching Section Search
👤

Human-in-the-Loop Handoff

Intelligent escalation from AI to live operator with full context transfer. Automatic triggers on frustration scoring (≥0.75) or repeated low-confidence responses. GDPR-compliant consent capture, real-time queue with position tracking, operator typing indicators, and session transcripts.

Queue Management GDPR Consent Context Package Socket.IO

Analytics & Observability

Real-time dashboard tracking intent distribution, session volumes, satisfaction ratings, and operator performance. System health monitoring covers CPU, memory, disk, and all service processes. Aggregated conversation logs with full message history and intent classification visibility.

Intent Analytics CSAT Ratings System Health Log Aggregation

Enterprise Data Ingestion

Knowledge base population from any enterprise source via 600+ Airbyte connectors (Confluence, Notion, Jira, Zendesk, GitHub, Google Workspace) and Firecrawl web crawling. Dynamic schema-driven configuration with scheduled synchronisation pipelines keeps the knowledge base current automatically.

Admin & Operator Console

Unified web portal for system configuration, theme customisation, live conversation monitoring, operator queue management, and ML Platform Studio (intent editor, response editor, training management). Role-separated access for administrators and operators via JWT-authenticated sessions.

Live Monitor Routing Rules Studio Editor JWT Auth

Native Mobile Application

Cross-platform iOS and Android app delivering the full chatbot experience with real-time operator handoff, conversation history, ITSM ticket management, file attachments, and session feedback. Built with Expo SDK — single codebase for both platforms with native performance.

Security & Compliance
Security Controls

Designed with enterprise security requirements from the ground up.

Identity & Access

ITSM directory authentication for end users. JWT-signed tokens for operator sessions with ITSM group membership enforcement. Guest access scoped to KB read-only.

Secrets Management

All credentials (ITSM tokens, DB passwords, JWT secrets, LLM keys) stored in Infisical vault. Environment-specific profiles (local / prod) with Universal Auth.

GDPR Compliance

Explicit opt-in consent before any conversation data is shared with a human operator. Consent logged with timestamp and IP hash. Configurable per deployment.

Input Guardrails

Client-side PII detection blocks SSN and credit card patterns. Profanity filtering and CAPS abuse prevention enforced before messages reach the AI engine.

The Six Ends of Project IQ
Each surface is purpose-built — the chatbot ships as two distinct channels (an embeddable web widget and a native mobile app) — yet they all share one identity layer, one data model and one real-time backbone.
💬
End-User · Browser
Web Chatbot
An embeddable Web Component — drop it into any website.
  • Embeddable widget — one tag, any site
  • Conversational AI — 45+ skills, multilingual + Arabic RTL
  • Self-service tickets — create, track, close from chat
  • Talk to a human — one-tap live handoff
📱
End-User · iOS & Android
Mobile App
A native cross-platform app (Expo) with full feature parity.
  • Native iOS & Android — one Expo codebase
  • Full feature parity — chat, tickets, handoff, same as web
  • Biometric unlock + stay signed in offline
  • Push notifications + camera/document capture
  • Offline queue — works with no connection

Operator End
Real-time console for escalated conversations.

⚡ Real-time & Self-HealingSocket.IO backbone · background workers · tracing▾

Real-time backbone

  • Socket.IO over eventlet, Redis bus for multi-worker fan-out
  • Room routing — per-user, per-operator, per-conversation
  • Sub-second delivery, even under load

Background workers

  • Queue timeout / SLA alerts & auto-abandon
  • Priority boost prevents starvation
  • Orphan-state healer — repairs stuck conversations

Tracing & alerting

  • End-to-end correlation IDs — admin API → NLU → ITSM
  • Error alerting, deduplicated & storm-capped

🔑 Single Sign-On

Keycloak OIDC, PKCE on web/mobile, offline refresh for persistent login.

🧭 Product-scoped sessions

Identity is iam-{user}-{product}; switching product starts a fresh, isolated session.

🔗 Identity pinned end-to-end

Proxy → bot → queue → operator → ITSM — scoping never drifts between layers.
🔐 Security & PrivacyEnforced server-side, every layer▾

🔐 Authentication

SSO-only via Keycloak; stateless JWTs validated against the realm. No passwords stored by the app.

🚧 Authorization

Per-tenant scoping on every endpoint; super-admin override only for platform members.

🕵️ GDPR & privacy

Consent gate before handoff; transcripts masked for passwords, cards & IBANs.

🧱 Data integrity

Parameterized queries; tenant identity sourced from the JWT, never the request body.

🗄️ Secure storage

Attachments via signed, expiring URLs — object storage never exposed to the browser.

🔑 Secrets & supply chain

No secrets in the repo; Dependabot + weekly pip-audit in CI.

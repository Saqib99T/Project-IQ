01 · SLA / OLA / UC built

A JSM/Zoho‑grade ticket‑SLA engine.

  • Agreements with a kind — sla / ola / uc, independently versioned
  • OLA/UC underpinning chains — breach walks the chain, attributes to team or vendor
  • Coverage windows — timezone, split shifts, holidays, follow‑the‑sun

  • At‑risk live board — compliance %, breach report, AI breach‑risk score
